# 单词成文 · Vocabulary Story

把一份单词表打乱顺序、编成一段连贯英文故事，做成「点击任意单词即显示中文」的网页。

## 这是什么

- 词表：103 个重点词（来自手写清单截图逐词识别、去重），已按故事需要彻底打乱顺序
- 正文：7 段连续故事，共 709 个单词（370 个不同词形），**每个单词都可点击**
- 重点词带虚线（按词性配色），点击额外显示词性、英文释义与「重点词」徽章；普通词只显示词性与中文
- 三种对照方式：点词浮层 / 逐词中文标注（对照）/ 整段中文译文（译文）
- 第二栏为乱序词卡，可反复重新打乱，逐张翻看

## 文件结构

| 文件 | 说明 |
|---|---|
| `vocab-passage.html` | 成品网页，单文件、零外部依赖，双击即可打开，离线可用 |
| `preview-words.png` | 整页长截图 |
| `build/SKILL.md` | 复现这套产出的操作规范（取词表 → 写故事 → 生成页面 → 校验） |
| `build/verify.py` | 校验脚本：词库数、实际用词数、段落与译文数是否一致、有无漏词 |
| `build/reference.html` | 版式与交互模板，新词表直接替换内容即可 |

## 怎么改内容

打开 `vocab-passage.html`，三处数据结构：

1. `const D = { ... }` —— 103 个重点词：`{p:词性, cn:中文, en:英文释义}`
2. `const W = { ... }` —— 普通词释义表，键为小写词形，值为 `{t:词性, c:中文}`
3. `<div id="passage">` —— 正文。重点词写作 `<w data-k="compel">compelled</w>`，普通词写作 `<w data-w="ledger">ledger</w>`；每段英文后紧跟 `<p class="zh">` 为该段中文译文

改完跑一次校验：

```bash
python3 build/verify.py vocab-passage.html
```
